Sen.Environment

The ultimate modding tool for PvZ2

About
  • Sen.Environment is a modding tool for PvZ2, designed to simplify the modding process and enhance the gaming experience.
Platform Support
  • Windows 10+
  • Sen.Environment is fully compatible with Windows, providing a seamless experience for modding PvZ2.
  • Android 10.0+
  • Sen.Environment is also available on Android, allowing users to enjoy modding on their preferred platform.
Modules
  • Kernel
  • The core of the Sen.Environment, providing essential functionalities and low-level operations.
  • Shell
  • A user interface for command processing and interaction with the kernel.
  • Script
  • A module for automation and scripting capabilities, allowing users to create custom scripts.
  • Modding
  • A module for game file modifications and management, enabling users to create and manage mods easily.
Technologies Used
  • Meson
  • Meson is a build system that is designed to be fast and user-friendly. It is used to build the Sen project.
  • Flutter
  • Flutter is a UI toolkit that is used to build the Sen project. It allows you to build beautiful and responsive user interfaces for mobile, web, and desktop applications.
